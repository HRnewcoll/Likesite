# Likesite – Gaming Sites & Trading Platforms

A collection of five fully-designed gaming site templates. Each site is self-contained with its own HTML, CSS, and JavaScript — no build tools or dependencies required.

---

## 📂 Sites

| Folder | Site Name | Type | Inspired By |
|---|---|---|---|
| `cs2-cases/` | **CS2Cases** | CS2 Case Opening | HellCase |
| `cs2-trading/` | **CS2Market** | CS2 Trading Platform | CS2Float / SkinBaron |
| `rust-trading/` | **RustTrade** | Rust Trading Platform | Rustyskins / Skinsmonkey |
| `tf2-trading/` | **TF2Bazaar** | TF2 Trading Platform | Backpack.tf / TF2.gg |
| `dota2-trading/` | **Dota2Items** | Dota 2 Trading Platform | OpenDota Market |

Open `index.html` in the root for the main landing page linking to all five sites.

---

## 🎮 Sites Overview

### CS2Cases (`cs2-cases/`)
A HellCase-style CS2 case opening site featuring:
- 6 different cases with weighted random items
- Animated spin reel with winning item selection
- Live drop feed scrolling banner
- Deposit system (UI)
- Full inventory with sell/keep options
- Win modal with celebration animation

### CS2Market (`cs2-trading/`)
A full CS2 skin trading marketplace:
- 22 listings with search, filter by category/rarity/price, and sort
- Grid and list views
- Item detail modal
- Buy skins, send trade offers (multi-item selection)
- List own items for sale
- Trade history table

### RustTrade (`rust-trading/`)
A Rust game skin trading platform:
- 22 Rust skins across Weapon, Clothing, Tool, Armor, and Misc categories
- Category buttons and quality filter
- Sales ticker scrolling banner
- Paginated market grid
- Inventory management with sell-all

### TF2Bazaar (`tf2-trading/`)
A Team Fortress 2 item trading platform:
- 20 items: Unusuals, Strange, Genuine, Vintage, Unique, Craft
- Keys + Refined Metal pricing system
- Quality color-coding matching TF2's actual colors
- Unusual showcase with effect labels
- Backpack grid view

### Dota2Items (`dota2-trading/`)
A Dota 2 item trading platform:
- 24 items across Arcana, Immortal, Legendary, Rare, Courier, Ward
- Filter by hero (10 heroes) and item type
- Featured Arcana and Immortal showcases
- Item detail modal with rarity-themed styling

---

## 🚀 Usage

Simply open any `index.html` file in a web browser — no server required.

```
open index.html               # Landing page
open cs2-cases/index.html     # CS2 Case Opening
open cs2-trading/index.html   # CS2 Trading
open rust-trading/index.html  # Rust Trading
open tf2-trading/index.html   # TF2 Trading
open dota2-trading/index.html # Dota 2 Trading
```
